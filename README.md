# ShuleFinance — Greenfield Academy

A premium, bilingual school finance staff portal prototype for Greenfield Academy. The current phase is frontend-only and uses realistic Kenyan mock data.

## Run locally

```bash
npm install
npm run dev
```

## Production check

```bash
npm run build
```

The app is organized by components and features. Every visual component has its own stylesheet, while shared design tokens and base controls live in `src/styles/global.css`.
